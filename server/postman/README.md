# Postman collection

[View the API documentation](https://documenter.getpostman.com/view/28699747/2sBYHNYPUM).

Base URL: `http://localhost:3001/api/`

| API | Method | Path |
| --- | --- | --- |
| getAllPuzzles | GET | `/getAllPuzzles` |
| getPuzzleById | GET | `/getPuzzleById/:id` |
| getCluesById | GET | `/getCluesById/:id/clues` |
| submitAnswer | POST | `/submitAnswer/:id/answers` |
| requestHints | PATCH | `/requestHints/:id/hint` |
